# Shopping Trends Analysis - Exploratory Data Analysis (EDA)

This repository contains my internship project focusing on Exploratory Data Analysis (EDA) of customer shopping trends, purchasing behaviors, and demographic preferences.

## Project Overview

Understanding consumer behavior is crucial for retail optimization, targeted marketing, and inventory management. This project analyzes a comprehensive customer shopping dataset to uncover actionable insights regarding purchasing habits, product preferences, payment methods, and demographic trends.

## Key Research Questions Addressed

* **Demographics & Behavior:** What is the overall age distribution of customers, and how do purchase frequencies vary across different age groups and genders?
* **Product Performance:** Which product categories and specific items drive the highest sales, and how do average purchase amounts and customer ratings vary across them?
* **Spending Drivers:** How do factors like seasonality, discounts, promo codes, and subscriptions impact customer spending and purchase decisions?
* **Logistics & Preferences:** What are the preferred shipping types and payment methods among different customer segments?
* **Regional & Product Attributes:** Are there noticeable differences in purchase behavior across locations, and do product attributes like size or color influence spending?

## Repository Structure

* `Project on EDA - Shopping Trends Analysis.ipynb`: The primary Jupyter Notebook containing the data cleaning, visualization, and exploratory analysis.

## Getting Started

To run this notebook locally:

1. Clone this repository.
2. Ensure you have Python installed along with the required data science packages (such as `pandas`, `numpy`, `matplotlib`, and `seaborn`).
3. Launch JupyterLab or Jupyter Notebook:
```bash
jupyter lab

```
4. Open `Project on EDA - Shopping Trends Analysis.ipynb` and run the cells.
